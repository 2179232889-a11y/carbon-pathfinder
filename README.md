## 主要功能

1. 新建和管理多个独立碳核算项目。
2. 维护采购、能源、物流等活动数据，支持 CSV 导入和排放复算。
3. 使用输入与输出碳质量天平校验核算边界。
4. 按重量、里程或货值分摊碳成本并追溯至作业和线路。
5. 模拟欧盟 CBAM 隐含排放、免费配额与关税成本。
6. 生成可追溯核算报告，支持打印、PDF 与快照分享。
7. 提供内置 CMC 演示项目用于完整业务流程展示。

## 数据说明

用户录入的项目、活动数据、碳流参数和情景参数保存在当前浏览器的 `localStorage` 中，不上传到服务器。清除浏览器站点数据会删除本地项目，请定期通过“核算项目”页面导出 JSON 备份。

报告分享链接通过 URL 编码保存当前项目快照。系统输出用于演示和辅助核算，不构成正式审计、鉴证或法律意见。
